### C4. Raw `{{quote:N}}` tags render as literal text in articles — ROOT CAUSE FOUND
- **No server-side renderer exists for `{{quote:…}}`.** `{{photo:…}}` is rendered by the `process_photos` Jinja filter (app.py:199-239, applied at templates/article.html:177), but quotes are rendered ONLY by client-side JS (inline IIFE, article.html:179-316).
- Served HTML contains literal tags → seen by curl, RSS readers, crawlers, no-JS clients; flash-of-raw-tags on every load.
- The IIFE is fragile: the lookbehind regex at article.html:280 is a **parse-time SyntaxError on Safari < 16.4** — on those iPhones the whole renderer never runs and every tag stays raw. (JS logic itself verified correct in headless Chromium.)
- **Fix:** add a `process_quotes` Jinja filter mirroring `process_photos` (handle `{{quote:SECONDS}}`, `{{quote:EVENT:SECONDS}}`, `{{quote:yt-ID:SECONDS}}`), chain it at article.html:177; keep JS as progressive enhancement.
- Related: `rag/publish_article.py:38,41` has a fatal **SyntaxError** (`re.findall(r{{quote:d+}}, …)` — missing quotes/escapes), so its orphan-tag-stripping safeguard never runs.
- Minor: single-number quote timestamps are LLM-approximate (~74s off in article 144).
- [ ] Implement `process_quotes` filter · [ ] fix publish_article.py · [ ] consider timestamp snapping to nearest chunk

### C5. Destructive admin endpoints are completely unauthenticated
- No auth anywhere in app.py (no session/login_required/before_request/token). Anyone can call:
  - `DELETE /api/photos/<id>` (app.py:1999) — deletes DB rows AND `os.remove()`s files
  - `POST /api/photos/<id>/feature` (:2017), `POST /api/photos/<id>/tags` (:2027)
  - `DELETE /api/comments/<id>` (:2094)
  - `POST /api/indexnow` (:1882)
- `/status` (:2455) publicly dumps log tails + `crontab -l`; `/review` (:2841) exposes unpublished drafts.
- [ ] Gate all mutating/admin routes (shared-secret header or session login); then CSRF tokens on form posts.

### C1b. (extends C1) OpenRouter keys retrievable from git HEAD

- [ ] `git rm --cached openrouter_credentials.json` + rotation (OWNER) + history purge before any push.
